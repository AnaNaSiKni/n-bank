# Н-банк

Учебный проект мини-интернет-банка на чистых HTML, CSS и JavaScript, без фреймворков и сборщиков.
Все данные вымышленные, это не настоящий банк.

**Демо:** https://ananasikni.github.io/n-bank/

## Возможности

- Карты, общий баланс, доходы и расходы за 30 дней
- Операции: поиск, фильтр по категории, сортировка, добавление, удаление, выгрузка в CSV
- Переводы между своими счетами и открытие новых карт
- Диаграмма расходов по категориям (canvas, без библиотек)
- Цели-копилки с прогрессом
- Вклады: сроки, ставки, досрочное закрытие, начисление процентов
- Кредиты: аннуитетный платёж, лимит по статусу, досрочное погашение
- Н-статус: уровень зависит от расходов и даёт бонусы к кэшбэку, ставкам и лимитам
- Калькулятор кэшбэка с лимитами по категориям и подбором лучших категорий
- Н-здоровье: оценка финансового состояния от 0 до 100 с советом
- Кнопка «Пропустить месяц» для демонстрации процентов и платежей
- Ограничения на суммы, проверка ввода, тёмная и светлая тема
- Данные сохраняются в `localStorage`

## Технологии

HTML5, CSS3 (Grid, Flexbox, CSS-переменные, `backdrop-filter`), JavaScript (ES6+), Canvas API, `localStorage`, `Intl`.

## Структура

```
n-bank/
├── index.html
├── css/style.css
└── js/
    ├── data.js      данные, константы и лимиты
    ├── finance.js   расчёты: статус, вклады, кредиты, здоровье
    ├── render.js    отрисовка страницы из данных
    └── app.js       события, проверки, изменение данных
```

## Запуск

Скачайте репозиторий и откройте `index.html` в браузере. Установка не нужна.
